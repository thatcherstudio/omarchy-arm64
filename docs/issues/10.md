## Steps

1. Pass OMARCHY_ARCH and Docker --platform using the qualified #2 image contract; validate inputs before privileged actions.
2. Keep channel/ref/local-source options compatible; document CLI overriding OMARCHY_ARCH and env/default behavior.

- [ ] No unqualified assertion that pacman automatically uses per-arch cache directories.
