## Steps

1. With UTM window open, copy unique text tokens host→guest and guest→host; verify equality rather than only process existence.
2. Verify one session agent, daemon options and clean behavior when the SPICE channel or folder is absent.
3. Test runtime resolution change without losing menu/keybindings; record actual monitor modes.
