## Objective

Produce an ARM ISO with complete provenance using the public native ARM runner. Do not close on a partial build or a renamed x86 artifact.

## Files

docs/evidence/builds/aarch64-build.md; docs/evidence/builds/artifacts.json; build manifests and checksums

## Steps

1. Build on native aarch64 with pinned inputs and a clean architecture-specific cache; collect duration, peak storage and failures.
2. Validate ARM EFI executable, squashfs architecture, actual kernel/initrd paths and the complete offline package closure.
3. Verify project and ALARM trust bootstrap from the live filesystem, matching runtime/settings and current setup form.
4. If mkarchiso needs changes, land a minimal tracked patch/PR and update pins; do not hand-patch the generated ISO.

## Acceptance criteria

- [ ] Build returns 0 and artifact is nonempty with SHA256 and source/package manifests.
- [ ] No required x86-only packages/EFI binaries in active ARM path.
- [ ] Estimated 30–60 minutes is a planning estimate only; record actual duration.
