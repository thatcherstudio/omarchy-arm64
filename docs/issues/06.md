## Objective

Determine the actual gaps, including transitive dependencies and ABI compatibility. The old approximate 25/17 package counts are not inputs.

## Files

docs/package-gap-analysis.md; packages/required-aarch64.txt; packages/sources.lock.json; packages/decisions.json; scripts/audit-package-closure.sh; docs/evidence/packages/

## Steps

1. Clone the pinned community repo for audit. Compare both Omarchy base/other lists, live releng list, archinstall.packages, selected runtime/settings/nvim and boot dependencies.
2. Record required, optional, substitute, excluded and missing per package, with version, source URL/ref, hash, signature, license, arch/provides and reason. Include kernel/headers, archiso/archinstall, fonts, keyring and quickshell.
3. Audit whole Hyprland/aquamarine/toolkit/guiutils/portal SONAME closure; reuse stage2 resolver logic. Do not mix feeds solely by newest version.
4. Inspect runtime/settings payloads for setup-form.sh and ARM boot omissions; community pair is Asahi-specific. Audit native payloads inside any packages, especially nvim.
5. Identify optional x86-only applications and explicit bounded skips (including opencode only if still unresolved). Confirm mise-bin provides/conflicts mapping and current nvim PKGBUILD path.

## Acceptance criteria

- [ ] No required target is silently omitted; machine-readable manifest reconciles all source lists.
- [ ] Clean ALARM resolver output and ELF/dependency audit back every reuse decision.
- [ ] Each gap has a build recipe or explicit optional exclusion; current publication deltas are documented.
