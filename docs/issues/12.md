## Objective

Make build/live/offline package lists and repository configuration consistent with the qualified ALARM and project snapshot.

## Files

builder/archinstall.packages; builder/build-iso.sh; configs/pacman-online-{stable,rc,edge}.conf; configs/pacman-offline.conf; tests/pacman-overlay.sh

## Steps

1. Use a shared list/filter, remove ARM microcode, syslinux, x86 firmware tools, arch-mact2 and unsupported multilib. Handle optional GPU/x86 packages from the audit rather than an ad hoc skip-all rule.
2. Generate ALARM $arch/$repo base paths and selected project feed across channels; do not route ARM base packages to stable-mirror.omarchy.org.
3. Bundle public keyrings and preserve signature checks for live and offline mirror, with a documented policy for generated offline DB signatures.
4. Do not silently map incomplete stable to mutable edge: use the locked snapshot or an actionable failure. Check local-source package output signing compatibility.

## Acceptance criteria

- [ ] ARM config contains no x86-only repo sections or unresolved required packages.
- [ ] x86 config remains equivalent; all supported ARM channel selections are explicit.
- [ ] Tampered offline package fixture is refused; keys persist into the target bootstrap.
