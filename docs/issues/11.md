## Objective

Parameterize the builder and live rootfs for ALARM using one profile. Delta: zstd already removed the BCJ requirement; retain it.

## Files

builder/build-iso.sh; builder/build-omarchy-packages.sh; configs/profiledef.sh; configs/airootfs/etc/mkinitcpio.d/; tests/build-overlay.sh

## Steps

1. Seed releng once, generate packages.aarch64 and filter x86-only releng entries using the audited manifest.
2. Select linux-arm64 Node tarball and verify checksum; x86 keeps linux-x64.
3. Use qualified linux-aarch64/preset/Image paths on ARM and omit linux-t2.preset. Preserve existing x86 T2 behavior.
4. Set arch and UEFI-only boot modes; retain zstd settings. Update all offline-mirror enumeration and expected-count inputs, including current builder extensions.
5. Bootstrap ALARM keyring/build dependencies before pacman; verify archiso package availability and keep gitlink pin. Add minimal recorded patches only if ARM tooling requires them.

## Acceptance criteria

- [ ] Generated ARM tree has correct arch, Node payload, kernel/preset and package-list filename.
- [ ] No accidental sed removes the selected ARM kernel; all package enumerations consume the same overlay.
- [ ] Source configs remain unchanged by generation; x86 overlay regression fixtures pass.
