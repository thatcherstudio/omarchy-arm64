## Objective

Boot the ARM live ISO through ARM UEFI without copying the x86 BIOS or EFI chain.

## Files

configs/grub/grub.cfg; configs/grub/loopback.cfg; configs/efiboot/loader/loader.conf; configs/efiboot/loader/entries/; configs/syslinux/ overlay selection; tests/live-boot-overlay.sh

## Steps

1. Port the upstream shared-template approach: generate ARM loader/default entries and correct kernel/initrd paths at build time.
2. Omit syslinux, shellx64/shellia32 and memtest fragments on ARM; retain x86 chain.
3. Verify pinned mkarchiso/grub supports aarch64-efi output and produces BOOTAA64.EFI with the correct PE architecture; handle ISO EFI image layout and firmware fallback.
4. Keep live GRUB boot separate from target Limine integration (#15).

## Acceptance criteria

- [ ] Generated ARM tree contains a valid ARM UEFI fallback binary and referenced kernel/initrd files.
- [ ] No BIOS/x86 shell or microcode path remains in active ARM boot configs.
- [ ] x86 boot fixture remains equivalent.
