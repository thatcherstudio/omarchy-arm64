## Objective

Make the installed target boot on generic UEFI ARM. Delta: the current Python orchestrator directly copies BOOTX64.EFI, and ARM settings packages omit Limine configuration for Asahi.

## Files

configs/airootfs/usr/share/omarchy-iso/orchestrator/phases_impl.py; archinstall_adapter.py; Configurator boot intent; packages/patches/ and generic-UEFI integration package from #7; tests/target-boot/

## Steps

1. Port BOOTAA64.EFI selection and ARM update-hook concepts from Armarchy install/login/limine-arm64.sh at the pinned ref, adapting to current orchestrator APIs rather than copying its 3.x script.
2. Handle normal/removable/pre-mounted EFI names, fallback boot with fresh NVRAM, architecture validation and ARM BIOS rejection.
3. Supply package-owned Limine hooks/settings/Snapper configuration missing from upstream ARM recipes; use linux-aarch64 Image/preset/headers paths and validate UKI generation on ARM.
4. Preserve root UUID, LUKS unlock, Btrfs subvolumes and snapshot boot behavior. Scope unsupported x86-oriented hibernation/hardware behavior explicitly.
5. Ensure package upgrades restore the same boot contract and hooks are not left masked.

- [ ] Tests cover both arch EFI binaries, correct loader/register paths, no ARM BIOS invocation and matching headers/kernel paths.
- [ ] Generic-UEFI boot dependencies and settings persist through package reinstall.
