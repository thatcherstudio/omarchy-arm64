## Objective

Prove the actual wanted path: native aarch64 UTM, not x86 emulation and not a prebuilt prior-art disk.

## Files

docs/utm.md; scripts/verify-installed-arm.sh; docs/evidence/validation/utm-install.md; artifact/log/screenshot index

## Steps

1. Document host model/macOS/UTM version, QEMU virtualization backend, CPU/RAM/disk/EFI/GPU settings and exact ISO hash.
2. Install to a fresh disposable disk via the Configurator, exercising encrypted Btrfs; capture all installer status and sanitized logs.
3. Detach ISO, reboot with fresh NVRAM as a fallback check, unlock and enter the Omarchy session.
4. Verify Hyprland + quickshell, menu, terminal, audio, DNS, default helper commands and required units. Check package ownership, matched runtime/settings, no dangling links and sane first-run completion.
5. Build a guest verification harness that emits a documented success line only after its checks; include failure cases. Do not reuse old BINS=445 counts as constants.

## Acceptance criteria

- [ ] Native guest uname is aarch64; reboot succeeds from disk alone.
- [ ] Hyprland/quickshell run with the actual Omarchy 4 configuration and core interactions work.
- [ ] Evidence includes actual serial lines, screenshots, package list and exit statuses; no falsely successful summary on failed checks.
