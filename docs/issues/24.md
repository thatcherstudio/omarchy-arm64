## Objective

Verify firmware → live kernel → Configurator before attempting the full user installation.

## Files

scripts/verify-live-arm.sh; docs/evidence/builds/qemu-live.md; serial log/checksum index

## Steps

1. Boot the exact #23 ISO with qemu-system-aarch64 -machine virt, ARM firmware and new writable variables. Use software emulation where native acceleration is unavailable.
2. Capture serial output and screenshot; verify Configurator picker inputs, ARM architecture, virtio storage/network and no emergency shell.
3. Inspect generated install configuration for kernel, mirrors, boot intent and package selection without touching non-test disks.
4. Create a bounded harness with machine-readable success only after observed readiness; save actual boot lines and reject timeout/kernel panic.

## Acceptance criteria

- [ ] Configurator is interactive and source/version provenance matches the artifact.
- [ ] Live system reports aarch64 and the selected kernel is present in the offline repo.
- [ ] Serial evidence distinguishes readiness from firmware-only boot.
