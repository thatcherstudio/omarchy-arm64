## Objective

Prove the installed system remains usable across full updates; exercise the ALARM /boot/Image trap rather than merely checking the source patch.

## Files

docs/runbooks/arm-update-recovery.md; tests/update-kernel-cases.sh; docs/evidence/validation/update-cycle.md

## Steps

1. On a disposable snapshot of #26 run omarchy-update with current packages: no perpetual kernel-reboot prompt.
2. Stage a real signed kernel update from a controlled qualified snapshot, run update, confirm reboot is requested, then reboot and confirm prompt clears.
3. Validate required non-kernel restart flags/services still work, mirrors/keyring stay correct and runtime/settings remain paired.
4. Create/restore a Snapper snapshot and verify boot after recovery; record expected package transitions and no skipped required migrations.
5. Show no dangling /usr/bin helpers or missing user units after update and subsequent login.

## Acceptance criteria

- [ ] Current → upgraded-not-rebooted → rebooted cases have correct prompt outcomes.
- [ ] Full update does not revert to x86 base mirrors or overwrite ARM integration.
- [ ] Recovery returns to a bootable desktop with logs and package provenance.
