## Objective

Close upstream prerequisite 4 early using a disposable ALARM VM/rootfs and the pinned installer stack. A systemd-boot desktop cannot close this gate.

## Files

docs/runbooks/limine-prereq.md; tests/prereqs/limine-receipt.schema.json; docs/evidence/limine-prereq.json; serial/boot logs referenced by checksum

## Steps

1. Use the qualified bootstrap to run the exact archinstall adapter/orchestrator on an explicitly identified scratch virtual disk; do not require the final custom ISO to perform this spike.
2. Install encrypted Btrfs, boot via Limine with fresh EFI variables, unlock, log in and create a Snapper snapshot.
3. Exercise a kernel upgrade/reboot and snapshot recovery; record package/kernel/archinstall/firmware/source versions and all failures.
4. If the combination fails, keep the gate open with a concrete follow-up; systemd-boot alternative needs a new ADR. Feed a hash-bound successful receipt into #4.

## Acceptance criteria

- [ ] Cold boot and reboot use BOOTAA64.EFI with correct LUKS/root mapping.
- [ ] Kernel update remains bootable and snapshot recovery is demonstrated.
- [ ] Probe script recognizes only a matching real receipt; attach actual log lines, not invented expected boot messages.
