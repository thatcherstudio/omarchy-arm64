## Objective

Select the correct QEMU/firmware/ISO artifacts without cross-architecture ambiguity.

## Files

bin/omarchy-iso-boot; bin/omarchy-vm; bin/omarchy-iso-release; related test/upload selection; tests/vm-release.sh; docs/building.md

## Steps

1. Select arch explicitly or from unambiguous filename and reject mismatches.
2. Use qemu-system-aarch64 -machine virt with appropriate CPU/acceleration, ARM firmware code plus a per-run writable VARS copy; discover distribution/macOS firmware names instead of assuming the same paths.
3. Keep x86 OVMF behavior; retain serial logs/timeouts and make firmware-missing errors actionable.
4. Parameterize release globs and artifact naming; constrain latest selection by arch/ref. Mock uploads in tests.

## Acceptance criteria

- [ ] Generated commands use matching QEMU, firmware, machine and ISO.
- [ ] Release cannot select or rename the other arch's output.
- [ ] Code firmware stays immutable and runs do not share writable NVRAM.
